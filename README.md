# Diod Sticks Mapper (DSM)

Универсальный Art-Net / sACN пиксель-маппер для TouchDesigner в виде одного `.tox`.

## Спеки разработки

Разработка идёт по SDD ([cc-sdd](https://github.com/gotalab/cc-sdd)): у каждой фичи своя спека,
фазы **требования → решение → шаги → реализация**, каждая фаза утверждается до перехода к следующей.
Папка спеки — `.kiro/specs/<имя>/` (`requirements.md`, `design.md`, `tasks.md`), появляется при старте спеки.

| № | Спека | Что внутри | Этап |
|---|---|---|---|
| — | этап 0 (без спеки) | репозиторий, cc-sdd, steering, проверки движка в TD | 0 |
| 1 | `patch-core` | модель патча, JSON-схема, адресация, проверки, импорт/экспорт CSV/JSON, pytest — без TD | 1 |
| 2 | `pixel-engine` | каркас tox, POP-геометрия из патча, выборка цвета, DMX-вывод, синхронизация с видео | 1 |
| 3 | `patch-view` | карта DMX по юниверсам, выходы и правила портов, переадресация перетаскиванием, конфликты | 1 |
| 4 | `mapping-editor` | холст INPUT / OUTPUT, инструменты, выделение, привязки, массивы, undo | 1–2 |
| 5 | `locate-test` | Locate: мигание, соло, направление, номер на пикселях, обход, сырой адрес, лист приёмки | 1 |
| 6 | `fixture-editor` | редактор профилей блоками, матрицы, бары с общими каналами, библиотека | 2 |
| 7 | `color-power` | 16 бит, RGBW, баланс белого, гамма, лимит мощности | 3 |
| 8 | `space-3d` | выходная карта в 3D, визуализатор | 3 |
| 9 | `palette-generators` | кнопка «Палитра»: из контента выделяются основные цвета, в маппер идёт поле из них — сегментированная картинка или один из 12 генераторов | 2 |

## О проекте

Вставляется в любой патч: на вход — TOP с видео, на выход — DMX для LED-стиков, лент,
матриц и пиксельных приборов, синхронно с видеоконтентом.

## Идея

Модель взята у Resolume Arena Advanced Output — библиотека фикстур, размещение фикстур
поверх картинки (Input Map), карта каналов (DMX), выходы-«лумиверсы». Её минусы закрыты:

| Resolume | DSM |
|---|---|
| только прямоугольники | линия, полилиния, кривая, дуга, матрица, своя таблица точек |
| выборка одной точкой в центре клетки | точка, область, вытянутая область (вдоль/поперёк ленты) |
| доп. каналы только до/после пикселей | профиль блоками: общие каналы → пиксельный блок со своими каналами ячейки → хвост |
| порядок цвета из меню, только 8 бит | порядок строкой (`GRB`, `BWGR`), RGBW/RGBWA, 8 и 16 бит |
| только Art-Net, без Net, ≤256 юниверсов на IP | Art-Net 4, sACN unicast/multicast с priority, IP на юниверс |
| не знает портов контроллера | универсальные правила порта: «с нового юниверса», выравнивание, пропуск 511–512, лимит пикселей |
| нет подсветки фикстуры | **Locate**: мигание, соло, направление, номер на самих пикселях, обход, тест по сырому адресу, лист приёмки |
| нет импорта, правки в XML | CSV/JSON, генератор массивов, Python-API |
| нет 3D | выходная карта в 3D и визуализатор (позже) |

## Принципы

1. **Движок не знает про железо.** Контроллер — это данные: IP, протокол, юниверсы.
   Никаких веток нод под конкретный контроллер.
2. **Патч — документ и источник правды** (JSON). Геометрия, адреса, маршрутизация,
   интерфейс и отчёты генерируются из него.
3. **Каждый кадр — только GPU** (POP и GLSL). Python — только при правке патча.
4. **Один вход TOP**, несколько копий в одном проекте, без абсолютных путей.
5. Интерфейс помещается в экран 1280×720.

## Конвейер кадра

```
вход TOP → подготовка → [Палитра: основные цвета → сегменты или генератор 1–12] → текстура
патч → (Python при правке) → POP: 1 примитив = 1 фикстура, 1 точка = 1 ячейка в порядке данных
  → выборка цвета → пиксельная обработка (Locate/тест, яркость, баланс белого, гамма, RGBW, лимит мощности)
  → DMX Fixture POP на каждый профиль → DMX Out POP на протокол (адрес и IP — атрибутами на фикстуру)
```

## Этапы

| Этап | Что |
|---|---|
| 0 | репозиторий, SDD, steering, проверки движка в TD |
| 1 — MVP | ядро патча и адресации, движок, линейные фикстуры, карта DMX, Locate |
| 2 | матрицы и бары с общими каналами, кривые, выборка по области, CSV, лист патча, Locate с телефона, Палитра и генераторы |
| 3 | цвет и мощность, задержка на выход, поиск узлов, 3D |

## Структура

```
src/core    ядро на чистом Python: модель патча, адресация, проверки, импорт/экспорт (pytest)
src/td      расширения и обработчики интерфейса для TouchDesigner
src/glsl    шейдеры
tests       тесты ядра
td          dev-проект .toe
release     собранный dsm.tox (релизы — в GitHub Releases)
examples    примеры патчей: ленты, стики, матрица, бар
tools       утилиты: перехват Art-Net/sACN, клиент TD
docs        документация
```
