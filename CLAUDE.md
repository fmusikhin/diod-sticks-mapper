# Diod Sticks Mapper — правила проекта

Универсальный Art-Net / sACN пиксель-маппер для TouchDesigner (`.tox`). Обзор — `README.md`.

## Порядок работы

- Сначала план → подтверждение заказчика → действия.
- SDD через cc-sdd: одна спека = одна фича; требования, решение и шаги утверждает заказчик,
  только потом реализация. Установщик cc-sdd в этой папке не запускать — он заменяет этот файл.
- Ветка на спеку (`spec/<имя>`), слияние в `main` через PR.

## Что нельзя нарушать

- Движок не знает про конкретные контроллеры: контроллер — только данные (IP, протокол, юниверсы).
  Никаких веток нод и захардкоженных размеров под железо.
- Патч (JSON) — источник правды; всё остальное генерируется из него.
- Каждый кадр — без Python: POP/GLSL; Python только при правке патча.
- Вывод по умолчанию на 127.0.0.1, пока у выхода не задан IP.
- Интерфейс помещается в 1280×720.
- В публичный репозиторий не попадают реальные IP, планы площадок и данные заказчиков.

## Проверка

- Ядро — `pytest` вне TD.
- В TD — сверка `DMX Map DAT` с ожидаемой таблицей адресов, перехват Art-Net/sACN байт в байт,
  замер стоимости кадра.
- «Готово» — только с фактом проверки.
