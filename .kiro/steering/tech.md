# Технологический стек

## Архитектура

Два слоя:

1. **Ядро на чистом Python** (`src/core`) — модель патча, JSON-схема, адресация, проверки, импорт/экспорт
   (CSV, JSON, пресеты Resolume). Не зависит от TouchDesigner, тестируется pytest.
2. **Слой TouchDesigner** (`src/td`, `src/glsl`, `td/`) — компонент `dsm.tox`: при правке патча Python
   строит POP-геометрию и таблицы; каждый кадр работает только GPU:
   вход TOP → (Палитра) → выборка цвета (POP) → пиксельная обработка (GLSL POP) →
   DMX Fixture POP на профиль → один DMX Out POP на протокол.

Контроллер — только данные: адрес задаётся атрибутами примитива (`DMXFixtureUniverse`, `DMXFixtureChannel`,
`DMXFixtureNetAddress`), веток нод под железо нет.

## Основные технологии

- **TouchDesigner 2025.33070** (POP-семейство, DMX Fixture POP, DMX Out POP, GLSL POP).
  Сейчас без лицензии (Non-Commercial: TOP ≤ 1280×1280) — движок от этого не зависит.
- **Python 3.11+** — встроенный в TD для слоя TD; системный Python 3.12 для ядра и тестов.
- **GLSL 4.30** — шейдеры POP и TOP.

## Ключевые библиотеки

- Ядро — только стандартная библиотека (json, dataclasses, csv, xml.etree): должно импортироваться внутри TD без установки пакетов.
- numpy — допустим в TD-слое (поставляется с TD).
- pytest — только для тестов.

## Стандарты разработки

### Типы
Аннотации типов в ядре; модель — dataclasses; JSON-схема патча версионируется (`schema_version`).

### Качество кода
Код с комментариями по-русски там, где неочевидно; никаких абсолютных путей; без Python каждый кадр.

### Тесты
- Ядро — pytest, без TD; каждый шаг спеки — с «чем проверено».
- TD — сверка DMX Map DAT с ожидаемой таблицей адресов, перехват Art-Net/sACN на 127.0.0.1 байт в байт,
  замер стоимости кадра, дым-тест `.tox` перед релизом.

## Среда разработки

### Инструменты
TouchDesigner 2025.33070 + плагин twozero (MCP, правка патча агентом), Python 3.12, git, gh.

### Команды
```bash
# Тесты ядра
python -m pytest tests
# Перехват Art-Net/sACN
python tools/dmx_listen.py artnet 2 cap.json
```

## Ключевые решения

- **Один DMX Out POP на протокол, DMX Fixture POP на профиль** — масштабируется на любое число контроллеров.
- **Патч — внешний JSON**, `.tox` — пустая заготовка: переносится в проект с лицензией без правок.
- **Без Git LFS**: источник правды — текст, `.tox` — в GitHub Releases.
- **Вывод по умолчанию на 127.0.0.1**, пока у выхода не задан IP.
